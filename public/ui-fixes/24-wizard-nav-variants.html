Wizard nav — новые варианты

Underline D отменяем. Свежие идеи для side-rail__nav (5 шагов торгового). Поверхность well как сейчас. Без правок приложения.

Уже смотрели в 22: stack · номера · прогресс · underline · stepper · chips · pager. Здесь H–M — другой характер: сегмент, минимум хрома, мягкий select, сетка, dropdown, content-width pills. Пиши букву.

H — Segmented track

Один «трек» как iOS segmented: активный — мягкая плашка внутри. Шаги делят ширину; если не влезают — горизонтальный скролл без underline.

На мобиле почти нет списка шагов: крупный заголовок текущего + тонкие сегменты-точки. Меньше шума при 5 шагах. Desktop — точки слева у названий.

J — Soft select / edge bar

Mobile: ширина по тексту, без растягивания на всю nav; активный — мягкий фон. Desktop: тихая полоска слева у активного (классика sidebar).

На мобиле шаги сеткой 3×2 — все видны сразу, без горизонтального скролла. Desktop — вертикальный список с номером справа.

M — Content-width pills

Горизонтальный ряд pill по ширине текста (не stretch). Активный — заливка, не линия. Fade справа если есть скролл. Ближе к chips из 22F, но без обводки у каждого.
