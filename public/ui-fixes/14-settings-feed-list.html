Настройки — feed list

Варианты композиции settings-detail-feed__list (токены + счета). Открытый токен — как сейчас.

A–D

Сейчас список — плоские строки с hairline, раскрытие превращает одну строку в карточку. Ниже четыре направления: оставить как есть, карточки с gap, общий inset-panel, или quieter rules без «коробки» у open.

A

Сейчас — hairline rows

Bleed ±10px, разделители между строками, is-open = bordered card 10px.

border-bottom · wrap.is-open { border + radius 10 }

B

Cards stack

Каждая строка — мягкая плитка с gap 6px. Нет hairline. Open усиливает border той же карточки.

flex gap 6 · row { bg + radius 10 } · без border-bottom

C

Inset panel

Весь list в одном inset (bg-input + border). Строки внутри с правилами; open «всплывает» панелью поверх.

list { panel } · wrap inset на panel bg

D

Quiet rules

Тоньше разделители, без hover-карточки. Open без рамки — только accent bar слева и well без фона.

hairline 55% · open { inset bar } · well flat
