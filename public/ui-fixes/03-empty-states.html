4. Что такое «пустые состояния»

Не про баги данных. Про то, как UI объясняет «почему здесь прочерк / ноль / пусто».

Коротко: сейчас в нескольких местах стоят «—» или пустые графики без причины. Пользователь не понимает: это ещё грузится, данных нет, ошибка, или раздел не для этой валюты? Предложение — одна короткая подсказка + CTA, где уместно.

Пример A — сводка USDT на дашборде

Сейчас
Сводка USDT
Собственные средства
—
Текущая стоимость
9,63 USDT
Общее изменение — · За день —
Предлагаю
Сводка USDT
Собственные средства
н/д
Текущая стоимость
9,63 USDT
Нет истории снимков по USDT — изменение и свои средства появятся после первого дня учёта.

Пример B — карточка ошибки в лаборатории

Сейчас
#236 momentum
Сделки 0 · Просадка — · Доход/риск —
ОШИБКА
Предлагаю
#236 momentum ОШИБКА
Нет свечей Bybit за 19.09–20.10. Открой прогон или сузь период.

Важно: пункт 1 говорит «аналитику убрать», поэтому пример C скорее для дашборда/портфеля/лаборатории, а не для отдельной страницы аналитики. Суть та же: не молчаливый «—».
