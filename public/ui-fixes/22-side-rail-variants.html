Side rail — варианты

Wizard `/robots/new` (+ тот же язык для settings broker). Mobile + desktop. Выбери букву.

A сейчас B номера C прогресс D underline E stepper F chips G pager

A — Сейчас (stack)

Номер над подписью, равная ширина слотов. На десктопе — подпись слева, номер справа в карточке-рельсе.

B — Только номера

На мобилке — крупные кружки + подпись текущего шага отдельной строкой. Нет обрезки длинных лейблов в слотах.

Один заголовок текущего шага + доля «1 / 4» и тонкая полоса. Переход — тап по сегментам или кнопки в футере карточки.

Только текст, все будущие шаги видны. Активный — нижняя линия (mobile) / тихий fill (desktop). Без кружков.

Классический wizard-stepper: узлы на оси, подписи мелкие. Хорошо читается «где я» и «сколько осталось».

F — Chips / scroll

Горизонтальные pill без растягивания. На 4 шагах обычно влезают; на узких экранах — лёгкий скролл, без сжатия текста.

G — Pager

Только текущий шаг + стрелки. Максимум места форме; прямого прыжка на шаг 3 нет (или прыжок через меню «⋯»).
